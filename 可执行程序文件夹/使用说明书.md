# TINY 编译器 GUI — 使用说明书

## 1. 概述

TINY 编译器 GUI 是一个基于 Qt 框架的图形化编译器前端，支持 TINY 扩展语言的词法分析、语法分析、语义分析和代码生成。

## 2. 系统界面布局

主界面分为以下几个区域：

| 区域 | 说明 |
|------|------|
| **工具栏** | 位于窗口顶部，包含"打开文件"、"保存文件"、"生成语法树"按钮 |
| **源代码编辑区** | 左侧区域，用于输入/编辑 TINY 源代码 |
| **结果展示区** | 右上区域，以选项卡形式显示分析结果（词法分析/语法树） |
| **信息输出区** | 底部区域，显示编译错误信息或成功提示 |

## 3. 功能操作说明

### 3.1 打开源代码文件

1. 点击工具栏上的 **打开文件** 按钮（📂 图标）
2. 在弹出的文件选择对话框中，选择 `.tny` 格式的 TINY 源代码文件
3. 文件内容将自动加载到左侧的源代码编辑区

### 3.2 编辑源代码

- 直接在左侧的 **Tiny源代码** 编辑框中输入或修改代码
- 支持基本的文本编辑操作（复制、粘贴、删除等）

### 3.3 保存源代码

1. 在源代码编辑区中输入或修改代码后
2. 点击工具栏上的 **保存文件** 按钮（💾 图标）
3. 选择保存路径和文件名，点击"保存"

### 3.4 编译生成语法树

1. 在源代码编辑区中输入代码，或打开一个 `.tny` 文件
2. 点击工具栏上的 **生成语法树** 按钮（▶ 图标）
3. 系统将自动执行以下操作：
   - 调用词法分析器对源代码进行词法分析
   - 调用语法分析器生成语法树
   - 执行语义分析

**查看结果**：
- **编译成功**: 右上方的"语法分析"选项卡中将以树形结构显示生成的语法树，底部的信息输出区显示"编译成功！语法树已生成。"（绿色文字）
- **编译失败**: 信息输出区将以红色文字列出所有错误信息及所在行号

### 3.5 查看语法树

- 编译成功后，切换到右上方的 **语法分析** 选项卡
- 语法树以树形控件展示，所有节点默认展开
- 每个节点显示对应的语法结构名称：
  - `If` — if 语句
  - `While` — while 循环
  - `For` — for 循环
  - `Assign to: x` — 赋值语句
  - `Read: x` — 读入语句
  - `Write` — 输出语句
  - `Op: +` — 运算符
  - `Const: 10` — 常量
  - `Id: x` — 标识符引用
  - `Regex Assign to: pattern` — 正则赋值

## 4. 支持的 TINY 语言语法

### 4.1 语句类型

| 语句 | 语法格式 | 示例 |
|------|----------|------|
| 赋值 | `id := expr;` | `x := x + 1;` |
| 输入 | `read id;` | `read x;` |
| 输出 | `write expr;` | `write x;` |
| 条件 | `if expr then stmt else stmt end` | `if x > 0 then write x end` |
| 循环 | `while expr do stmt endwhile` | `while x < 10 do x := x + 1 endwhile` |
| for循环 | `for(id := expr; expr; inc) stmt` | `for(i := 0; i < 10; ++i) write i` |
| 正则赋值 | `id ::= regex;` | `pattern ::= a | b & c #;` |

### 4.2 运算符

| 类别 | 运算符 |
|------|--------|
| 算术 | `+` `-` `*` `/` `%` `^` |
| 比较 | `=` `<` `>` `<=` `>=` `<>` |
| 自增/减 | `++` `--` |
| 正则 | `|` `&` `#` `?` |

## 5. 常见问题

**Q: 编译后没有反应？**
A: 请检查源代码编辑区是否有代码内容，以及语法是否正确。

**Q: 如何查看词法分析结果？**
A: 切换到右上方的"词法分析"选项卡即可查看。

**Q: 编译错误信息如何理解？**
A: 错误信息会显示"语法错误，行 N：错误描述"，根据提示检查对应行号的代码即可。
