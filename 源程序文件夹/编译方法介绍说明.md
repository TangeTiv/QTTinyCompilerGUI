# TINY 编译器 — 编译方法介绍

## 概述

本实验实现了一个面向 **TINY 扩展语言** 的小型编译器，包含完整的词法分析、语法分析、语义分析和代码生成阶段。编译器采用 **递归下降分析法**，目标代码为 **TM（Tiny Machine）模拟器** 的汇编指令。

## 编译器工作流程

```
源代码(.tny) → 词法分析 → Token 流 → 语法分析 → 语法树 → 语义分析 → 注释语法树 → 代码生成 → TM汇编代码(.tm)
```

### 1. 词法分析 (Scanner)

- **源文件**: `scanner.cpp` / `scanner.h`
- 从左到右扫描源代码，识别出各类词法单元（Token）
- 支持的词法单元类型包括：
  - **保留字**: IF, THEN, ELSE, END, REPEAT, UNTIL, READ, WRITE, WHILE, ENDWHILE, FOR
  - **标识符** (ID) 和 **数字** (NUM)
  - **运算符**: +, -, *, /, =, <, >, <=, >=, <>, ++, --, %, ^, :=, ::=
  - **逻辑运算符**: | (OR), & (AND)
  - **正则运算符**: # (CLOSURE), ? (OPTIONAL)
  - **分隔符**: (, ), ;

### 2. 语法分析 (Parser)

- **源文件**: `parser.cpp` / `parser.h`
- 采用 **递归下降分析法**，根据 TINY 语言的文法规则构建语法树
- 支持以下语句结构：
  - `if-then-else-end` 条件语句
  - `while-endwhile` 循环语句
  - `for` 循环语句（支持 ++ 和 --）
  - `read` / `write` 输入输出语句
  - 赋值语句（`:=`）和正则赋值语句（`::=`）

### 3. 语义分析 (Analyzer)

- **源文件**: `analyzer.cpp` / `analyzer.h`
- 构建 **符号表**（`symtab.cpp` / `symtab.h`），管理变量作用域
- 进行类型检查，确保表达式类型一致

### 4. 代码生成 (Code Generator)

- **源文件**: `cgen.cpp` / `cgen.h`
- 将语法树转换为 TM（Tiny Machine）汇编代码
- 使用 `code.cpp` / `code.h` 中的工具将指令输出到目标文件

### 5. 辅助工具

- **`util.cpp` / `util.h`**: 通用工具函数，包括语法树打印等
- **`globals.h`**: 全局类型定义（TokenType、TreeNode 结构体等）

## 扩展特性（相对标准 TINY 编译器）

1. **扩展运算符**: %（取模）、^（幂运算）、++（自增）、--（自减）
2. **扩展比较**: <=（小于等于）、>=（大于等于）、<>（不等于）
3. **while 循环**: 支持 while-endwhile 结构
4. **for 循环**: 支持 for 循环及自增/自减操作
5. **正则表达式赋值**: 支持 ::= 运算符及 |、&、#、? 正则操作
6. **GUI 界面**: 基于 Qt 框架的图形用户界面

## 开发环境

- **编程语言**: C++17
- **框架**: Qt 6.9.1 (Widgets)
- **编译器**: MinGW 64-bit
- **构建工具**: QMake
